<h2>What I Learned from This Project and Why It Might Be Useful One Day</h2>
This project was developed to study and understand, in practice, how a biometric verification system works, exploring the concepts behind this technology and its integration into modern applications.

Objectives
This project aims to demonstrate knowledge in:

<ol>
<li>Biometric verification</li>
<li>Modern authentication</li>
<li>Integration with biometric APIs</li>
<li>Information security</li>
<li>User experience in authentication processes</li>
</ol>
